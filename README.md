# D.A. Estruturas Metálicas

Landing page estática criada como projeto de extensão em front-end para apresentar serviços de uma empresa de estruturas metálicas. A interface inclui navegação por seções, apresentação institucional e conteúdo de serviços.

## Como visualizar

Abra `src/index.html` em um navegador. Os estilos ficam na pasta `src/styles/`.

A página referencia Font Awesome, Google Fonts, jQuery e ScrollReveal por CDN; é necessária conexão com a internet para carregar esses recursos.

## Tecnologias

- HTML
- CSS
- JavaScript
